# Калькулятор подъёма материалов

Одна страница без сборки: `index.html` — разметка, стили и скрипт в одном файле.
Внешних зависимостей нет, кроме шрифтов Google Fonts.

## Откуда взялась эта версия

Исходников калькулятора с `kalculator-podcheta.ersenovkajrat3.workers.dev`
в репозиториях не было, а сам воркер из рабочего окружения не открывается.
Страница собрана заново по описанию задачи («Расчет стоимости подъёма
материалов») — считайте её рабочим черновиком, а не копией прежней версии.
Тарифы и состав материалов почти наверняка нужно заменить на свои.

## Размер ДСП

Базовая позиция — **ДСП 2440 × 1830 × 16 мм**: 4,465 м² и ≈50 кг при плотности
плиты около 700 кг/м³. Размер взят из карточки Профкома,
`product/listovie_materialy/dsp/dsp_24400h1830h16_mm.html`.

В адресе карточки лишняя цифра (`24400`), так что формально он читается и как
4400 мм. Проверьте по карточке: если там 4400 × 1830 × 16, поправьте строку
`dsp-2440` в массиве `MATERIALS` — длину в названии, `m2` (4,4652 → 8,052) и
`kg` (50,0 → 90,2).

## Как считается

| Условие | Формула |
|---|---|
| Без лифта | `вес × тариф_без_лифта × (этаж − 1)` |
| Грузовой лифт | `вес × тариф_лифта` (этаж не влияет) |
| Пассажирский лифт | листы длиннее 1600 мм считаются как ручной подъём, остальное — по тарифу лифта |
| Пронос от машины | первые 30 м бесплатно, далее `вес × тариф × каждые 10 м` |
| Минимум заказа | итог не может быть меньше этой суммы |

Первый этаж не тарифицируется — подъём считается со второго.
Порог 1600 мм — это `PASSENGER_LIMIT` в скрипте: длина, при которой лист
перестаёт влезать в пассажирскую кабину.

## Как менять

**Тарифы** правятся прямо на странице в блоке «Тарифы» и сохраняются в
`localStorage` того браузера, где их ввели. Чтобы поменять значения по
умолчанию для всех, отредактируйте `DEFAULT_RATES` в `index.html` — и там же
значения `value` у полей `r-nolift`, `r-lift`, `r-free`, `r-carry`, `r-min`.

**Материалы** — массив `MATERIALS`:

```js
{id:"osb-9", name:"ОСБ-3 2500 × 1250 × 9 мм", kg:18.0, m2:3.125, dim:2500}
```

`kg` — вес единицы, `m2` — площадь листа (у мешков и кирпича `0`, тогда
площадь не показывается), `dim` — наибольший габарит в мм, по нему решается,
влезет ли позиция в пассажирский лифт.

## Деплой на Vercel

Проект статический, сборка не нужна.

1. Vercel → Add New → Project → импортируйте этот репозиторий.
2. **Root Directory = `kalkulyator`** — это обязательно: в корне репозитория
   лежит ещё папка `site` с другим проектом.
3. Framework Preset — Other. Build Command и Install Command оставьте пустыми.

Дальше каждый push в ветку обновляет сайт сам.

Локально достаточно открыть `index.html` в браузере — сервер не нужен.
